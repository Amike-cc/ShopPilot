# 工具目录

这里存放不参与应用运行时打包的开发、验收和发布工具。所有工具都从仓库根目录解析路径，因此移动工具文件不会改变 `release/`、`apps/` 或 `packages/` 的位置。

## 目录约定

- `acceptance/`：M0–M4、安全验收脚本，以及一键验收入口。
- `release/`：发布清单、GitHub Release 上传、更新链路演练。
- `ui/`：窗口、布局和 UI 视觉探针；默认使用临时 userData。
- `maintenance/`：图标生成、源码导出等维护工具。

验收脚本只用于验证，不属于产品运行时；生成的日志、截图和打包产物保持在仓库根目录或已配置的忽略目录中，不混入工具源码目录。

仓库级日志统一写入根目录 `logs/`；应用运行时日志仍写入用户数据目录 `%APPDATA%\shopilot\logs\`。
