Layer & rhythm

信息层级由「块 → 组 → 卡 → 行」四级承载，不靠加大字号区分。

L0应用外壳侧栏 232 + 顶栏 56，固定不滚z 0
L1页头标题 / 副标题 / 主次行动z 0
L2筛选条搜索 300 + chips + 排序 + 视图z 10
L3推荐位132 高，唯一渐变块，全局只此一处z 0
L4卡片网格3 列 / gap 14 / 卡内边距 16z 20 on hover
L5浮层下拉 / 抽屉 / 确认浮层z 100–900
L6通知Toast，右下，最多 3 条z 1000
