# 应用中心 · 设计说明

高保真稿：`index.html`（1440 × 1220，可直接交互：搜索、分类、收藏、网格/列表切换、标注开关）
配套图：`app-center-screen.png` / `app-center-annotated.png` / `app-center-states.png` / `app-center-spec.png`

## 一、模块层级（对应标注图编号 1–8）

| 层 | 模块 | 位置与尺寸 | 职责 |
|---|---|---|---|
| L0 | ① 侧栏 | 232px 固定，右侧 1px 边线 | 全局导航；当前项 = 浅紫底 + 左侧 3px 竖条 + 数字徽章 |
| L0 | ② 顶栏 | 56px 高，sticky | 面包屑 + 全局跳转搜索 + 通知/头像；与页内搜索职责区分（顶栏=跳页面，页内=筛应用） |
| L1 | ③ 页头 | 标题 26/700 | 说明「这是什么 + 能做什么」，右侧放主次行动（新建=主，导入=次） |
| L2 | ④ 筛选条 | 36px 控件行 | 搜索 300px + 分类 chips + 排序 + 视图切换，是页面的唯一控制中心 |
| L3 | ⑤ 推荐位 | 132px 通栏 | 全页唯一渐变色块，用于「已接入能力」的强引导，不可复制到卡片 |
| L3 | ⑥ 分组头 | 19px 行 | 分组名 + 计数胶囊 + 次级入口（管理分类） |
| L4 | ⑦ 卡片网格 | 3 列 / gap 14 | 应用的最小完整单元，等高对齐 |
| L4 | ⑧ 底部条 | 分隔线 + 左统计右操作 | 结果计数与「已显示 / 总数」的诚实反馈 |

**层级关系**：侧栏与顶栏是「外壳」，不随内容滚动；③④ 是「控制层」，决定下面看什么；⑤⑥⑦⑧ 是「内容层」，按 推荐 → 分组 → 卡片 → 汇总 自上而下阅读。视觉权重靠**面积与色彩占用**区分，不靠加粗字号。

## 二、栅格与间距

- 内容区左右 24px，顶部 18px，底部 24px；主区可用宽 1160px。
- 卡片 3 列：`(1160 − 14×2) / 3 ≈ 377px`，卡内 padding 15px。
- 间距只用 4 的倍数：4 / 8 / 12 / 14（网格专用）/ 16 / 18 / 20 / 24。
- 圆角三级：卡片 14 · 控件 9 · 胶囊 999；小徽章 4–5。
- 卡片行高固定 `min-height:35px` 的简介区，保证同一网格内所有卡等高、状态行齐底。

## 五、卡片解剖（377 × 约 168）

```
┌──────────────────────────────┐
│ [44 图标·圆角12]        ☆    │  ← 图标与收藏，视觉锚点
│ 名称 14.5/650  [v4.2][Beta]  │  ← 版本/状态标签贴标题右侧
│ 简介两行 11.5/18，超出省略    │  ← 固定 2 行高度，保证对齐
│ ──────────────────────────── │  ← 1px #F0F2F8，只在卡内
│ ● 12 个店铺 · 在线      打开 →│  ← 状态点 + 事实数据；箭头仅 hover 出现
└──────────────────────────────┘
```

要点：
- 简介**只写能力，不写营销词**；状态行写**可验证的事实**（数量、时间、运行中）。
- 禁用卡改虚线边 + 灰阶图标 + `暂不可用` 胶囊，且不响应 hover，避免"看起来能点"。
- 卡片没有任何投影，仅 1px 描边；投影只在悬停时出现，避免满屏灰雾。

## 六、交互状态（对应 `app-center-states.png`）

| 状态 | 表现 |
|---|---|
| 默认 | 1px `#E7E9F2` + `0 1px 2px rgba(16,24,40,.03)` |
| 悬停 | `translateY(-2px)`、描边转 `#D2C6FF`、双层投影（紫偏移）、图标 `scale(1.04)`、`打开 →` 淡入 |
| 按下 | 回落到 `-1px`，底色 `#F4F3FC`，内阴影 1px |
| 键盘聚焦 | `2px #6D4AFF` outline + offset 2，仅在 `:focus-visible` 出现 |
| 运行中 | 状态点呼吸动画（2s），卡片内可加 3px 进度条；图标极缓呼吸 |
| 不可用 | 虚线边、图标 `grayscale(1)` + 0.55 透明、无 hover、`tabindex="-1"` |
| 加载 | 骨架：32 图标 + 3 条 9/7/7px，`1.4s` 扫光，不跳动布局 |
| 空结果 | 虚线容器 + 图标 + 一句原因 + 一个「清除筛选」出口 |

筛选行为：搜索实时过滤（名称 + 简介关键词），分类与搜索**取交集**，计数与 `已显示 / 总数` 同步刷新；0 结果时网格塌陷为空态，不保留空行。

## 七、落地映射（`apps/desktop/src/renderer/src/features/workbench/UnifiedAppsPage.vue`）

1. 现有 2 列 `.app-card-grid` → 3 列 `repeat(3,minmax(0,1fr))`，卡片补 `ac-top / ac-title / ac-desc / ac-foot` 四段结构。
2. 新增 `.filterbar`（搜索 + chips + 排序 + 视图）、`.hero` 推荐位、`.section-head` 分组头、`.strip` 统计条。
3. 数据层把现有 `appLinks` 扩成 `{ key, label, desc, icon, tone, cat, version, status: {kind, text}, disabled }`，`cat` 驱动筛选，`status.kind` 驱动状态点颜色。
4. 让 token 落到全局：`--dash-*` 已有变量对齐 `--ink-*` / `--line` / `--brand`；卡片不要出现 `#fff` 硬编码（深色主题会崩）。
5. 验收锚点建议保留：`unified-apps-page` / `.app-card` / `.chip` / `.search` / `#resultCount`，新增 `data-cat` 便于脚本点选。

## 八、边界

- 屏宽 < 1100 时降 2 列；< 780 时单列并隐藏推荐位的右侧统计块。
- 应用数 > 24 时按品类分组渲染，分组头复用 ⑥，不引入新的区块样式。
- 分类为 0 时该 chip 置灰不可点，不弹空分组。
